# 7.1 注意力

回顾第 5 章，对于 word2vec 和其他静态嵌入，无论上下文如何，一个词的意义表示始终是同一个向量。例如，chicken 总是由同一个固定向量表示。因此，词 it 的静态向量或许能以某种方式编码“它是一个用于动物和无生命实体的代词”这一信息。但在具体上下文中，it 的意义要丰富得多。请看下面两个句子中的 it：

(7.1) The chicken didn’t cross the road because it was too tired.

(7.2) The chicken didn’t cross the road because it was too wide.

在 (7.1) 中，it 指 chicken（即读者知道是鸡累了）；在 (7.2) 中，it 指 road（读者知道是路太宽）。[^1] 也就是说，要计算句子的意义，就必须使第一句中 it 的意义与 chicken 相关联，而第二句中 it 的意义与 road 相关联；这种表示必须对上下文敏感。

进一步考虑像因果语言模型一样从左向右阅读，把句子处理到 it 为止：

> (7.3) The chicken didn’t cross the road because it

此时，我们还不知道 it 最终会指代哪个事物！因此，这一时刻的 it 表示可能同时包含 chicken 和 road 的某些方面，就像读者正在猜测接下来会发生什么。

词语与可能相距很远的其他词语存在丰富语言关系，这一事实贯穿整个语言系统。再看两个例子：

(7.4) The keys to the cabinet are on the table.

(7.5) I walked along the pond, and noticed one of the trees along the bank.

在 (7.4) 中，短语 The keys 是句子的主语。在英语及许多语言中，主语必须与动词 are 在语法数上保持一致；这里两者都是复数。在英语中，不能让 is 这样的单数动词与 keys 这样的复数主语搭配（第 19 章将进一步讨论一致关系）。在 (7.5) 中，根据 pond 等上下文词语，我们知道 bank 指池塘或河流的岸边，而不是金融机构（第 9 章将进一步讨论词义）。

这些例子的共同要点是：帮助我们计算词语上下文意义的词，可能在句子或段落中相距很远。Transformer 可以整合这些有帮助的上下文词语之意义，构建词义的**上下文表示**（contextual representation），即**上下文嵌入**（contextual embedding）。在 Transformer 中，我们逐层构建越来越丰富的输入词元意义上下文化表示。在每一层，模型把上一层中关于词元 $i$ 的信息与相邻词元的信息结合起来，为每个位置上的每个词产生上下文化表示。

**注意力**（attention）是 Transformer 中的一种机制：它对第 $k$ 层上下文中其他适当词元的表示进行加权和组合，从而构建第 $k+1$ 层的词元表示。

![](../images/figure7.3.jpg)

**图 7.3 第 $k+1$ 层计算词 it 的表示时所用的自注意力权重分布 <sub>α</sub>。计算 it 的表示时，我们以不同程度关注第 $k$ 层中的各个词；颜色越深，表示自注意力值越高。请注意，Transformer 高度关注与词元 chicken 和 road 对应的列。这一结果十分合理，因为 it 出现时既可能与 chicken 共指，也可能与 road 共指，所以我们希望 it 的表示能利用这些先前词语的表示。图片改编自 Uszkoreit（2017）。**

图 7.3 展示了一个根据 Transformer 简化而来的示意例子（Uszkoreit, 2017）。图中描述的情形是：当前词元为 it，我们需要利用所有先前词元在第 $k$ 层的表示，计算该词元在 Transformer 第 $k+1$ 层的上下文表示。图中以颜色表示上下文词语上的注意力分布：词元 chicken 和 road 都具有较高的注意力权重，这意味着在计算 it 的表示时，我们会重点利用 chicken 和 road 的表示。这有助于构建 it 的最终表示，因为 it 最终会与 chicken 或 road 其中之一共指。

下面介绍这种注意力分布如何表示和计算。

## 7.1.1 注意力的形式化描述

如前所述，注意力计算是一种为 Transformer 特定层中的某个词元计算向量表示的方法：它有选择地关注并整合上一层中先前词元的信息。注意力接收与位置 $i$ 上输入词元对应的输入表示 $\pmb { x } _ { i }$，以及由先前输入 $\mathbf { x } _ { 1 } . . \mathbf { x } _ { i - 1 }$ 构成的上下文窗口，并产生输出 $\mathbf { a } _ { i }$。

在因果式、从左到右的语言模型中，上下文可以包含任意先前词语。也就是说，处理 $\mathbf { x } _ { i }$ 时，模型既能访问 $\pmb { x } _ { i }$，也能访问上下文窗口中所有先前词元的表示（上下文窗口可包含数千个词元），但不能访问 $i$ 之后的词元。（相比之下，第 9 章会把注意力推广为也能向前查看未来词语的形式。）

图 7.4 展示了整个因果自注意力层中的信息流；同样的注意力计算会在每个词元位置 $i$ 上并行执行。因此，一个自注意力层把输入序列 $\left( \mathbf { x } _ { 1 } , . . . , \mathbf { x } _ { n } \right)$ 映射为同样长度的输出序列 $\left( \mathbf { a } _ { 1 } , . . . , \mathbf { a } _ { n } \right)$。

![](../images/figure7.4.jpg)

**图 7.4 因果自注意力中的信息流。处理每个输入 $\mathbf { x } _ { i }$ 时，模型会关注直到并包括 $\mathbf { x } _ { i }$ 在内的所有输入。**

注意力的简化版本 从本质上说，注意力其实只是上下文向量的加权和；复杂之处在于如何计算权重以及具体对什么求和。出于教学目的，我们先介绍一种简化的注意力直觉：词元位置 $i$ 上的注意力输出 $\mathbf { a } _ { i }$，就是所有 $j \leq i$ 的表示 $\mathbf { x } _ { j }$ 的加权和。我们用 $\alpha _ { i j }$ 表示 $\mathbf { \boldsymbol { x } } _ { j }$ 应当对 $\mathbf { a } _ { i }$ 贡献多少：

$$
\text { Simplified   version: } \quad \mathbf {a} _ {i} = \sum_ {j \leq i} \alpha_ {i j} \mathbf {x} _ {j}\tag{7.6}
$$

每个 $\alpha _ { i j }$ 都是一个标量：对输入求和以计算 $\mathbf { a } _ { i }$ 时，它用于给输入 $\mathbf { \boldsymbol { x } } _ { j }$ 的值加权。这个 <sub>α</sub> 权重应当怎样计算？在注意力机制中，我们根据每个先前嵌入与当前词元 $i$ 的相似程度，按比例为它加权。因此，注意力的输出是先前词元嵌入的总和，每个嵌入的权重取决于它与当前词元嵌入的相似度。我们使用点积计算相似度分数；点积把两个向量映射为一个取值从 $-\infty$ 到 $\infty$ 的标量。分数越大，所比较的向量越相似。随后使用 softmax 对这些分数进行归一化，得到权重向量 $\alpha _ { i j }, j \leq i$。

$$
\text { Simplified   Version: } \quad \operatorname{score} (\mathbf {x} _ {i}, \mathbf {x} _ {j}) = \mathbf {x} _ {i} \cdot \mathbf {x} _ {j}\tag{7.7}
$$

$$
\alpha_ {i j} = \operatorname{softmax} (\operatorname{score} (\mathbf {x} _ {i}, \mathbf {x} _ {j})) \forall j \leq i\tag{7.8}
$$

因此，在图 7.4 中，我们通过计算三个分数 $\mathbf { x } _ { 3 } \cdot \mathbf { x } _ { 1 }$、$\mathbf { x } _ { 3 } \cdot \mathbf { x } _ { 2 }$ 和 $\mathbf { x } _ { 3 } \cdot \mathbf { x } _ { 3 }$ 来计算 $\mathbf { a } _ { 3 }$；再用 softmax 将其归一化，并把所得概率作为权重，表示各输入与当前位置 3 的相对相关程度。当然，$\mathbf { x } _ { i }$ 的 softmax 权重很可能最高，因为 $\pmb { x } _ { i }$ 与自身非常相似，会产生很高的点积。但其他上下文词也可能与 $i$ 相似，softmax 同样会给这些词分配一定权重。然后，我们把这些权重作为公式 7.6 中的 <sub>α</sub> 值，计算加权和 $\mathbf { a } _ { 3 }$。

公式 7.6–7.8 中的简化注意力展示了计算 $\mathbf { a } _ { i }$ 的注意力方法：把 $\pmb { x } _ { i }$ 与先前向量比较，把分数归一化为概率分布，再用该分布为先前向量之和加权。现在，我们可以去掉这些简化。

使用查询、键和值矩阵的单个注意力头 在理解注意力的简单直觉后，下面介绍真正的**注意力头**（attention head），也就是 Transformer 实际使用的注意力版本。（在 Transformer 中，head 一词经常用于指特定的结构化层。）注意力头使我们能够分别表示每个输入嵌入在注意力过程中扮演的三个不同角色：

• 当前元素，与先前输入进行比较。我们把这一角色称为**查询**（query）。

• 作为先前输入，与当前元素进行比较，以确定相似度权重。我们把这一角色称为**键**（key）。

• 最后，作为先前元素的**值**（value），经过加权和求和，用于计算当前元素的输出。

为了表示这三个不同角色，Transformer 引入权重矩阵 $W^{Q}$、$\boldsymbol { \mathsf { W } } ^ { \mathsf { K } }$ 和 $\boldsymbol { \mathsf { W } } ^ { \boldsymbol { \mathsf { V } } }$。这些权重把每个输入向量 $\pmb { x } _ { i }$ 投影为它充当查询、键或值时的表示：

$$
\mathbf {q} _ {i} = \mathbf {x} _ {i} \mathbf {W} ^ {\mathsf {Q}}; \quad \mathbf {k} _ {i} = \mathbf {x} _ {i} \mathbf {W} ^ {\mathsf {K}}; \quad \mathbf {v} _ {i} = \mathbf {x} _ {i} \mathbf {W} ^ {\mathsf {V}}\tag{7.9}
$$

有了这些投影，计算当前元素 $\pmb { x } _ { i }$ 与某个先前元素 $\mathbf { x } _ { j }$ 的相似度时，我们会计算当前元素的查询向量 $\mathbf { q } _ { i }$ 与先前元素的键向量 $\mathbf { k } _ { j }$ 之间的点积。此外，点积结果可以是任意大的正值或负值；对很大的值取指数可能造成数值问题，并使训练期间的梯度丢失。为避免这一问题，我们根据嵌入大小对点积进行缩放：除以查询和键向量维度 $d_k$ 的平方根。因此，我们用公式 7.11 取代简化的公式 7.7。随后产生 $\alpha _ { i j }$ 的 softmax 计算保持不变，但注意力头的输出现在以值向量 $\mathbf v$ 的加权和为基础（公式 7.13）。

下面给出从单个输入向量 $\mathbf { x } _ { i }$ 计算单个自注意力输出向量 $\mathbf { a } _ { i }$ 的最终公式。该版本通过求先前元素值的总和来计算 $\mathbf { a } _ { i }$；每个值的权重由其键与当前元素查询的相似度决定：

$$
\mathbf {q} _ {i} = \mathbf {x} _ {i} \mathbf {W} ^ {\mathrm{Q}}; \quad \mathbf {k} _ {j} = \mathbf {x} _ {j} \mathbf {W} ^ {\mathrm{K}}; \quad \mathbf {v} _ {j} = \mathbf {x} _ {j} \mathbf {W} ^ {\mathrm{V}}\tag{7.10}
$$

$$
\operatorname{score} \left(\mathbf {x} _ {i}, \mathbf {x} _ {j}\right) = \frac {\mathbf {q} _ {i} \cdot \mathbf {k} _ {j}}{\sqrt {d _ {k}}}\tag{7.11}
$$

$$
\alpha_ {i j} = \text { softmax } (\text { score } (\mathbf {x} _ {i}, \mathbf {x} _ {j})) \forall j \leq i\tag{7.12}
$$

$$
\mathbf {h e a d} _ {i} = \sum_ {j \leq i} \alpha_ {i j} \mathbf {v} _ {j}\tag{7.13}
$$

$$
\mathbf {a} _ {i} = \mathbf {h e a d} _ {i} \mathbf {W} ^ {0}\tag{7.14}
$$

图 7.5 以计算序列中第三个输出 $\mathbf a_3$ 的值为例，展示了这一过程。

请注意，我们还引入了一个矩阵 $\boldsymbol { \mathsf { W } } ^ { 0 }$，它与注意力头相乘。为了重塑注意力头输出的形状，这个矩阵是必需的。注意力输入 $\mathbf { x } _ { i }$ 和注意力输出 $\mathbf { a } _ { i }$ 都具有相同的维度 $[1 \times d]$。我们经常把 $d$ 称为**模型维度**（model dimensionality）。正如第 7.2 节将讨论的，每个 Transformer 块的输出 $\mathbf { h } _ { i }$ 以及 Transformer 块内部的中间向量，也都具有相同的维度 $[1 \times d]$。所有内容具有相同维度，使 Transformer 具有很强的模块化特性。

![](../images/figure7.5.jpg)

**图 7.5 使用因果式（从左到右）自注意力，计算序列第三个元素 $\mathbf a_3$ 的值。**

下面讨论各张量的形状。我们如何从输入处的 $[1 \times d]$ 得到输出处的 $[1 \times d]$？来看全部内部形状。查询向量和键向量使用维度 $d_k$，两者的维度均为 $[1 \times d_k]$，因此可以计算点积 $\pmb q_i \cdot \pmb k_j$，得到一个标量。值向量另用维度 $d_v$。变换矩阵 $\boldsymbol { \mathsf { W } } ^ { \mathbf { Q } }$ 的形状为 $[d \times d_k]$，$\boldsymbol { \mathsf { W } } ^ { \mathsf { K } }$ 为 $[d \times d_k]$，$\boldsymbol { \mathsf { W } } ^ { \mathsf { V } }$ 为 $[d \times d_v]$。因此，公式 7.13 中 $\mathrm{head}_i$ 的输出形状为 $[1 \times d_v]$。为了得到所需的输出形状 $[1 \times d]$，必须重塑注意力头输出，所以 $\mathsf W^O$ 的形状为 $[d_v \times d]$。在最初的 Transformer 工作中（Vaswani et al., 2017），$d$ 为 512，$d_k$ 和 $d_v$ 均为 64。

多头注意力 公式 7.11–7.13 描述的是单个注意力头。但实际上，Transformer 会使用多个注意力头。其直觉是，每个头可能出于不同目的关注上下文：不同的头可以专门表示上下文元素与当前词元之间不同的语言关系，或者在上下文中寻找特定类型的模式。

因此，在**多头注意力**（multi-head attention）中，同一模型深度上并行排列着 $A$ 个独立注意力头。每个头都有自己的一组参数，使它能够对输入之间关系的不同方面进行建模。于是，自注意力层中的每个头 $c$ 都有自己的查询、键和值矩阵：$\boldsymbol { \mathsf { W } } ^ { \mathrm { Qc } }$、$\boldsymbol { \mathsf { W } } ^ { \mathrm { Kc } }$ 和 $\boldsymbol { \mathsf { W } } ^ { \mathrm { Vc } }$。模型用这些矩阵把输入投影为每个头各自的查询、键和值嵌入。

使用多个头时，输入和输出仍采用模型维度 $d$；查询与键嵌入的维度为 $d_k$，值嵌入的维度为 $d_v$。（在最初的 Transformer 论文中，$d_k=d_v=64$、$A=8$、$d=512$。）因此，对每个头 $c$，权重层 $\boldsymbol { \mathsf { W } } ^ { \mathrm { Qc } }$ 的形状为 $[d \times d_k]$，$\boldsymbol { \mathsf { W } } ^ { \mathrm { Kc } }$ 的形状为 $[d \times d_k]$，$\boldsymbol { \mathsf { W } } ^ { \mathrm { Vc } }$ 的形状为 $[d \times d_v]$。

下面是在注意力中加入多个头之后的公式；图 7.6 展示了其直观原理。

$$
\mathbf {q} _ {i} ^ {c} = \mathbf {x} _ {i} \mathbf {W} ^ {\mathbf {Q c}}; \quad \mathbf {k} _ {j} ^ {c} = \mathbf {x} _ {j} \mathbf {W} ^ {\mathbf {K c}}; \quad \mathbf {v} _ {j} ^ {c} = \mathbf {x} _ {j} \mathbf {W} ^ {\mathbf {V c}}; \quad \forall c 1 \leq c \leq A\tag{7.15}
$$

$$
\operatorname{score} ^ {c} \left(\mathbf {x} _ {i}, \mathbf {x} _ {j}\right) = \frac {\mathbf {q} _ {i} ^ {c} \cdot \mathbf {k} _ {j} ^ {c}}{\sqrt {d _ {k}}}\tag{7.16}
$$

$$
\alpha_ {i j} ^ {c} = \text { softmax } (\text { score } ^ {c} (\mathbf {x} _ {i}, \mathbf {x} _ {j})) \forall j \leq i\tag{7.17}
$$

$$
\mathbf {h e a d} _ {i} ^ {c} = \sum_ {j \leq i} \alpha_ {i j} ^ {c} \mathbf {v} _ {j} ^ {c}\tag{7.18}
$$

$$
\mathbf {a} _ {i} = \left(\mathbf {h e a d} ^ {1} \oplus \mathbf {h e a d} ^ {2} \dots \oplus \mathbf {h e a d} ^ {A}\right) \mathbf {W} ^ {O}\tag{7.19}
$$

$$
\text { MultiHeadAttention } (\mathbf {x} _ {i}, [ \mathbf {x} _ {1}, \dots , \mathbf {x} _ {i - 1} ]) = \mathbf {a} _ {i}\tag{7.20}
$$

请注意，在公式 7.20 中，MultiHeadAttention 是当前输入 $x_i$ 以及所有其他输入的函数。对于本章使用的因果式或从左到右注意力，其他输入只位于左侧；第 9 章还会介绍一种注意力版本，其中注意力也是右侧词元的函数。公式 7.35 引入屏蔽右侧上下文的概念时，我们将重新讨论因果输入这一思想。

$A$ 个头中的每个头，其输出形状都是 $[1 \times d_v]$。因此，具有 $A$ 个头的多头层会输出 $A$ 个形状为 $[1 \times d_v]$ 的向量。把它们拼接起来，可得到维度为 $[1 \times A d_v]$ 的单个输出。随后再使用一个线性投影 $\mathsf { W } ^ { \mathbf { O } } \in \mathbb { R } ^ { A d _ { v } \times d }$ 重塑该输出，最终在每个输入位置 $i$ 得到输出形状正确、为 $[1 \times d]$ 的多头注意力向量 $\mathbf a_i$。注意力头的维度 $d_v$ 被设为 $d_v=d/A$，这意味着多头注意力的参数开销与单个注意力头大致相同。

[^1]: 我们称第一个例子中的 it 与 chicken 共指，第二个例子中的 it 与 road 共指；第 24 章将再次讨论这一问题。
