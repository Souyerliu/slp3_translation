# H.2 模型论语义学

意义表示语言为什么能够满足前述要求，从形式表示跨越到对世界中某种事态有所陈述的表示？答案在于**模型**（model）。模型是代表世界中特定事态的形式构造。意义表示语言中的表达式可以映射到模型中的元素，例如对象、对象的属性以及对象之间的关系。如果模型准确捕捉了我们关心的事实，那么意义表示与模型之间的一致映射，就在意义表示与世界之间架起了桥梁。模型由此提供了一种简单而强有力的方法，使意义表示语言中的表达式获得落地的解释。

意义表示的词汇表由两部分组成。**非逻辑词汇表**是一个开放集合，包含我们要表示的世界中的对象、属性和关系的名称；在不同体系中，它们可能表现为谓词、节点、边上的标签，或框架槽位的标签。**逻辑词汇表**则是一个封闭集合，包括符号、运算符、量词和连接词等，用来按给定意义表示语言的规则组合表达式。

非逻辑词汇表中的每个元素都必须在模型中具有一个**指称**（denotation），即对应模型中固定且定义明确的部分。模型的**论域**（domain）是被表示对象的集合；每个不同的概念、类别或个体都指称论域中的某个元素。

模型用拥有某一属性的论域元素来表示该属性，因此属性的指称是集合。例如，属性 *red* 的指称就是我们认为是红色的事物集合。对象之间的关系则指称由参与该关系的论域元素组成的有序表（即元组）集合；例如，关系 *Married* 的指称是所有已婚对象对的集合。这种用外延来定义概念的方式称为**外延式**（extensional）方法。概括而言：

- 对象指称论域中的元素；
- 属性指称论域元素的集合；
- 关系指称论域元素元组的集合。

还需要一个把意义表示映射到相应指称的函数，即把非逻辑词汇表映射到模型中适当指称的**解释**（interpretation）。

回到餐厅建议应用。设论域 $\mathcal D$ 包含餐厅、顾客、顾客偏好以及餐厅菜系、价格和噪声水平等事实。四位顾客 Matthew、Franco、Katie 和 Caroline 分别指称论域元素 $a,b,c,d$；三家餐厅 Frasca、Med 和 Rio 分别指称 $e,f,g$；三种菜系 Italian、Mexican 和 Eclectic 分别指称 $h,i,j$。这里故意使用无助记意义的字母，是为了强调：我们关于实体的一切知识都必须来自模型的形式属性，而不是符号名称。

属性 *Noisy* 指称已知嘈杂餐厅的子集；二元关系 *Likes* 指称顾客与其喜欢餐厅所形成的有序对集合；因为菜系也被当作对象，*Serves* 关系同样可表示为餐厅与菜系的元组集合。一个可能的模型如下。

| 项目 | 模型中的指称 |
| --- | --- |
| 论域 | $\mathcal D=\{a,b,c,d,e,f,g,h,i,j\}$ |
| Matthew、Franco、Katie、Caroline | $a,b,c,d$ |
| Frasca、Med、Rio | $e,f,g$ |
| Italian、Mexican、Eclectic | $h,i,j$ |
| $Noisy$ | $\{e,f,g\}$ |
| $Likes$ | $\{\langle a,f\rangle,\langle c,f\rangle,\langle c,g\rangle,\langle b,e\rangle,\langle d,f\rangle,\langle d,g\rangle\}$ |
| $Serves$ | $\{\langle f,j\rangle,\langle g,i\rangle,\langle e,h\rangle\}$ |

**图 H.2　餐厅世界的一个模型。** 其中 Frasca、Med、Rio 都很嘈杂；Matthew 喜欢 Med，Katie 喜欢 Med 和 Rio，Franco 喜欢 Frasca，Caroline 喜欢 Med 和 Rio；Med、Rio、Frasca 分别供应混合、墨西哥和意大利菜。

有了这一方案，就可以查找相应指称来使意义表示落地。例如，要验证“Matthew 喜欢 Frasca”，先由解释函数把 Matthew 映射到 $a$，把 Frasca 映射到 $e$，再把 *Likes* 映射到相应元组集合。如果集合中存在 $\langle a,e\rangle$，该命题为真；否则就不能断言它为真。

更复杂的例子还涉及合取、相等、量化变量和否定：

> **(H.13)** Katie 喜欢 Rio，并且 Matthew 喜欢 Med。  
> **(H.14)** Katie 和 Caroline 喜欢相同的餐厅。  
> **(H.15)** Franco 喜欢嘈杂且昂贵的餐厅。  
> **(H.16)** 并非每个人都喜欢 Frasca。

这些表示不会直接映射到单一对象、属性或关系。为了判断它们是否同模型一致，必须把表达式分解，分别判断各部分，再从各部分的意义组合出整体意义。

以（H.13）为例，其意义表示包含两个由合取运算符连接的命题。模型无需另外存储每对顾客与餐厅的组合偏好：只需知道 Matthew 喜欢 Med、Katie 喜欢 Rio，即 $\langle a,f\rangle$ 和 $\langle c,g\rangle$ 都属于 *Likes* 的指称，再给出合取的语义即可。若英语 *and* 取最简单的合取语义，则两个分句均为真时整体为真；本例中两个元组都存在，因此整句为真。

这就为合取运算符提供了**真值条件语义**（truth-conditional semantics）：复杂表达式的真值由其组成部分的意义（通过查询模型获得）和运算符的意义（通过真值表获得）共同决定。意义表示语言必须对其全部逻辑词汇给出这种形式语义，才能系统地从部分的意义确定整体的意义。尽管具体做法依表示体系而异，判断上述例子的真值条件本质上仍是集合及其运算。下一节将在一阶逻辑的语义中进一步讨论这一点。
