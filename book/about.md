# 关于本项目

本电子书整理自 *Speech and Language Processing* 第三版的中文翻译工作稿，使用 Jupyter Book 2、MyST Document Engine 和 MyST `book-theme` 构建。

## 内容组织

原书按章拆分，每章进一步按 section 保存为独立 Markdown 文件。电子书只展示已经完成整章翻译和基础整理的章节；未完成章节保留在翻译进度页中。

每个章首页都提供“原始 PDF”链接，方便对照对应章节的英文原稿。

## 版本说明

这是持续更新的非官方翻译工作版本。若译文与原文存在差异，请以章首页链接的原始 PDF 为准。
